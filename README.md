# A Birthday Wish for Kalou

A responsive birthday page made with plain HTML, CSS, and JavaScript.

## Publish with GitHub Pages

This is a static site and works with GitHub Pages. Keep `index.html`, `style.css`, `script.js`, and the complete `media` folder together. All site assets use relative paths, so the page also works when published from a repository subpath. In the repository settings, enable Pages and select the branch and folder containing `index.html`.

## View the page

Open `index.html` in a browser. Kalou's attached photo and video memories are included in the `media` folder. `1.jpeg` is the first portrait on the page; the other two photos appear as framed posters beside the birthday message and personal note, and all five videos appear in the memories gallery.

## Birthday playlist

The two attached tracks are included as `media/track-one.mp3` and `media/track-two.mp3`. The opening **Happy birthday, Kalou** link starts the playlist from your click and opens the page. Track one plays, then track two, and the playlist repeats in that order. Music pauses while a video is playing. The top-right music button lets you pause and resume the playlist. Each video has a synced MP3 copy of its original sound and a separate **Sound on** control. Keep the media files in the repository when publishing so the page can load them.

The video players use their own first frame as the preview, rather than a separate photo.

The page can be personalized by editing the birthday message and sign-off in `index.html`.
